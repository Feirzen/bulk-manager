Paste a GitHub key once per device and the workout page can save straight to your log. The key stays in this browser only. It is never put in the repo.

Making a key, about two minutes:

  1. Open GitHub's new token page and sign in.
  2. Name: anything, like bulk-manager iPhone. Expiration: 1 year.
  3. Repository access: Only select repositories, then pick bulk-manager.
  4. Permissions: Repository permissions, find Contents, set it to Read and write. Leave everything else alone.
  5. Generate, copy it, paste it above, tap Save key.

That key can only touch this one repo. One key works on every device, or make one per device so you can cancel one without the others. If a phone is ever lost, delete its key on that same GitHub page.
